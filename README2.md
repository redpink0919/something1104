# 천안 청년정책 인터랙티브 웹 프레젠테이션

원본 PPT 10장을 바탕으로 제작한 **서버 없는 정적 웹사이트**입니다. 외부 프레임워크·CDN·API·데이터베이스가 필요하지 않습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 동영상 재생은 브라우저 보안 설정에 따라 `http://localhost` 또는 GitHub Pages에서 더 안정적입니다.

## GitHub Pages 게시

1. GitHub에서 새 공개 저장소를 만듭니다.
2. 이 폴더의 `index.html`, `assets/`를 **저장소 최상위(root)**에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. Branch를 `main`, Folder를 `/ (root)`로 설정해 저장합니다.
5. 게시된 `https://<계정>.github.io/<저장소명>/` 주소에서 확인합니다.

모든 이미지와 동영상은 상대 경로(`assets/...`)를 사용하므로 프로젝트 저장소 하위 URL에서도 작동합니다.
